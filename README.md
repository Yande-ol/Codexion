# Codexion

## Description

**Codexion** is a multithreading and concurrency project written in C, inspired by the classic Dining Philosophers problem.

The simulation models coders in a shared co-working space competing for limited hardware tokens (USB dongles) needed to compile their code. Each coder alternates between compiling, debugging, and refactoring while managing burnout deadlines, resource cooldowns, and fair scheduling policies (FIFO and EDF) using POSIX threads and synchronization primitives.
